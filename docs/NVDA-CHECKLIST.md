# NVDA 수동 수용 점검

상태: 미실시. Linux 자동 테스트만으로 이 목록을 통과 처리하지 않습니다. NVDA를 사용하는 검토자가 실제 배포 주소에서 검증한 후 기록하세요.

기록: 날짜 / 배포 커밋 / 앱·은행 버전 / Windows 버전 / Chrome 또는 Edge 버전 / NVDA 버전 / 음성·점자 설정 / 확대 배율.

1. Tab으로 본문 바로가기 → 주요 메뉴를 이동합니다. 초점이 잘 보이고 NVDA 제목 목록/랜드마크로 탐색됩니다
2. 필기 설정에서 과목·모드·문항·보기 수의 레이블과 현재값을 확인합니다. 문항 수 과다/제한시간 0 입력 오류가 해당 입력과 연결되고 입력이 보존됩니다
3. 가능한 문항 수로 축소한 사실을 확인하고 시작 전 안내를 읽습니다. 시간은 실제 시작 버튼 이전에 흐르지 않습니다
4. 라디오 그룹에서 질문과 보기 번호·내용·선택 상태를 읽습니다. 방향키로 바꾸어도 다음 문제로 이동하지 않습니다
5. 무제한 답 확정 후 정오/해설을 읽고 이전·다음에서 제목 초점과 저장된 선택을 확인합니다. 문제목록 응답/표시/확정 상태도 읽힙니다
6. 시간제1분 세트를 시작합니다. 종료 전 정답·해설·AI 프롬프트가 NVDA 탐색에도 없습니다. 남은 시간을 매초 읽지 않고 확인 버튼/한 번의 경고/종료 안내를 구별합니다
7. 새로고침·백그라운드·탭 닫고 복귀 후 같은 문항·보기 순서·선택·만료시각인지 확인합니다. 만료 후 입력이 점수에 추가되지 않습니다
8. 같은 세션을 다른 탭에서 열 때 편집이 잠기거나 충돌 안내가 나며 조용한 덮어쓰기가 없습니다
9. 종료 확인에서 응답·미응답 수, 최종 제출/중단/취소의 효과가 명확합니다. 종료 후 결과 제목으로 초점이 갑니다
10. 실기 파일 선택, 원본 코드 읽기/선택/복사, 특정 줄/과제 구간 이동, 별도 줄 번호 보기, 빈칸 입력/단일/복수 선택이 가능합니다. 복사 코드에 줄 번호가 섞이지 않습니다
11. 실기 자유 서술이 미채점으로 표시됩니다. 프롬프트 미리보기에서 사용자 답/참고답/평가기준이 구분됩니다. 복사 실패 시 전체 선택·Ctrl+C·텍스트 다운로드가 가능합니다
12. 학습 기록에서 테스트/일반,시간제/무제한,필기/실기를 바꿔 읽습니다. 정답률의 분모와 미응답을 이해할 수 있습니다
13. JSON 백업 왕복, 합치기/교체 확인, 잘못된 파일 오류를 키보드로 완료합니다. 백업 개인정보 경고가 읽힙니다
14. 200%·400% 확대와 320 CSS px 폭에서 주요 버튼이 사라지지 않고 문서 본문에 불필요한 가로 스크롤이 없습니다. 코드는 자체 영역에서만 가로 스크롤됩니다
15. 저장·복사 성공 메시지는 초점을 뺏지 않습니다. 첫 live region 메시지도 읽히는지 확인합니다. 저장 실패 시 입력을 멈추고 백업·재시도로 접근할 수 있습니다

## 0.2.2 수정 집중 점검 (아직 수동 미실시)

- label의 for="ticket-email" 문항을 채점 전 읽을 때 완성 코드·파일 선택·복사·줄 번호 토글이 탐색/초점 목록에 없는지 확인합니다. 채점하고 해설을 열면 해설 코드가 나타나야 합니다
- 정답/오답 해설 제목을 각각 “정답입니다.” / “오답입니다.”로 한 번 읽는지 확인합니다. 같은 보기 이유가 공통·문맥으로 두 번 읽히지 않고, DNS/HTTP처럼 다른 이유는 모두 읽혀야 합니다
- CSS 명시도·JavaScript 계산 필기, 실기 구현·점검의 필요한 코드는 채점 전에도 읽고 선택·복사·줄 이동이 가능해야 합니다
- 즉시 해설, 종료 후 해설, 시간제 제출/만료, 이전 세션 재개와 뒤로/앞으로 이동에서도 공개 시점이 유지되는지 확인합니다
- AI 미리보기는 채점·해설 공개 전 독립 자료만 선택 가능하며 참고 정답·평가 기준·해설 코드가 없어야 합니다. 시간제 진행 중에는 미리보기가 비활성입니다
- 용도 미확인 이전 자료에서는 숨긴 이유와 새 문제 은행 연습 준비 버튼을 읽을 수 있어야 합니다. 진행 중 기록을 조용히 바꾸지 않아야 합니다

차단: 읽을 수 없는 문제/정답, 키보드 함정, 초점 소실, 제출 전 정답 누출, 기록 소실, 종료 중복. 발견 시 정식 접근성 검증 완료를 선언하지 말고 재현 단계·영향·브라우저/NVDA 버전을 남깁니다.
