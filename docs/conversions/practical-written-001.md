## 검토와 추적

[등록 대장](practical-written-001.json)은 후보별 원본 ID·revision·해시, 비교한 기존 필기 ID, 실제 검토 시각, 출제자와 다른 독립 풀이·출처·문안 검토, 다섯 gate 및 공개 입력의 바이트 해시를 연결한다. 원본 학습 목표의 대표 적용 판단을 복제·가공했으며 새 지식34개를 발견했다는 뜻은 아니다. 구현·디버깅·실제 보조기술 측정은 실기에 남긴다.

P1의 시작한 검토28회와 변경 없는4문항의 별도 출처 재결박을 보존한다. P2는21회(15문항1회·3문항2회)이며 합계49회다. G22 발문의 수정 방향 단서, G25 controls와 브라우저 조작부의 관계, G26 비활성 코드의 보조 근거를 보완했다. 첫 검토의 실패 기록을 지우지 않았고 수정한3개는 키를 보지 않은 새 풀이자가 재검토했다. 내용이 같은6개는 객체 동일성을 확인해 원 검토를 재사용했다.

기준판은 2026-05-07 출제기준, KWCAG2.2(KS X OT0003:2022), HTML5.2(2017-12-14), WAI-ARIA1.2(2023-06-06)다. DOM4·ECMAScript2015는 해당 코드 해석의 보충 근거이며 새 시험 지정판으로 간주하지 않는다. 고정 HTML5.2의 큰 media/forms 본문 신규 취득 실패는 한계로 남기고 확인한 공식 검색 발췌·기존 확인 기록을 구분해 사용했다. 모든 본문을 이번에 새로 내려받았다는 주장은 하지 않는다.

## 실행과 공개의 경계

이 등록의 원 대장 `publication`은 등록 당시의 `not_attempted`로 고정한다. 실제 공개 성공은 해당 커밋의 Pages 성공과 공개 manifest·은행 바이트를 확인한 뒤 별도 증거로 기록한다. 등록만으로 공개 완료를 뜻하지 않는다.

등록 경계는 정확한 대장·원본·최종 입력·과거 이력·양쪽 동결 상태를 검증한다. 최종 산출물에는 프로젝트 테스트, 격리 빌드, 통합 릴리스 및 archive 복원 검증과 필요한 앱 회귀를 적용하고 실제 결과를 별도 보관한다. 실제 Windows/NVDA 또는 다른 화면 낭독기 조합의 검사는 수행하지 않았으며 개발자 미리보기의 한계를 유지한다. 새 실기 형식 개편은 이번 변경에 포함하지 않는다.
