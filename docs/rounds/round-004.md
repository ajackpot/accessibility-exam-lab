새 공유 역할 2개·새 실기 1개의 대표 UI 흐름을 검사했으며 신규 58개나 전체 245개를 모두 수동으로 풀었다는 뜻은 아니다. 실제 150분/300분 만료 대기, 파일 선택기로 백업을 가져오는 흐름, Windows/NVDA 음성·OS 접근성 이벤트, 실제 모바일·확대·지원 브라우저 전체 조합, 외부 AI 전송은 미실시다. 다운로드 파일의 파싱·비교와 격리 저장소 가져오기 검사는 이 한계를 대신하지 않는다.
