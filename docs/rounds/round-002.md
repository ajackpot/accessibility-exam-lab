## 판정에서 고친 문제

- finally 해설을 정상 완료 조건으로 한정하고 키보드 함정 수정에 필요한 기존 입력 동작 보존 조건을 풀이 전에 명시했다
- TCP의 네트워크 도착 순서와 애플리케이션 전달 순서를 분명히 구별하고 두 RFC 출처의 절 번호·제목을 바로잡았다. 이전 검토 근거를 덮어쓰지 않고 정정된 출처 카드를 별도로 연결했다
- 링크와 같은 문단의 관계, KWCAG의 끌기 예시 근거, 입증책임 오답의 중복 의미를 점검하고 수정했다
