# 접근성 실무 학습 범위 확장 PRD — 공개용 사본

문서 기준: 2026-10-27 / PRD 1.3의 공개 가능한 요구사항을 정리한 사본. 이 문서는 학습 범위와 실행 계획을 보존한다. 전체 문제 은행·프로젝트·학습 기록의 복원 백업을 대신하지 않는다.

## 목적과 보존 기준

캠페인 시작 기준인 필기 921문항·연결 선택지 4,571개와 실기 8대문항을 보존하면서 실무에서 전이 가능한 지식을 확장한다. 기존 고급 문항을 삭제하는 작업이 아니며 문항 수를 학습 범위의 충실도와 동일시하지 않는다. 구형 실기 원본은 내부 보존하고 현재 서비스의 선택·출제·검색·새 세션 및 공개 산출물에 다시 포함하지 않는다. 과거 학습 기록·답안·점수·순서·스냅샷과 변경 이력을 보존한다.

E01 공개 완료 기준은 필기 927문항·연결 선택지 4,601개·실기 8대문항이다. 이후 회차의 실제 등록·공개 수는 완료 기록으로 구분하며 계획상의 목표 수를 문항 수로 세지 않는다.

애플리케이션 접근성 개발 과목은 가장 마지막 후속 범위이며 이번 PRD에서 제외한다. 해외 지침·테스트 실무·장르별 지식은 기존 과목의 확장 모듈로 배치한다. 독립 선수 체계·학습 성과·검증 책임이 커졌을 때만 과목 분할을 재검토하며 문항 수 증가만으로 자동 분할하지 않는다. 앱 명칭과 메뉴 변경은 포함하지 않는다.

## 범위 축과 포함 원칙

범위의 넓이, 전문화 정도, 관계의 깊이를 구별한다. 개론·원론과 분론·각론을 분리하되 적용·분석·종합평가라는 인지 수준을 범위 난이도 축으로 삼지 않는다. 개론에도 깊은 적용과 판단이 필요하다.

여러 접근성 직무에 전이되는 공통필수·범용 선택 목표를 포함한다. 전이성·활용 빈도·영향·검색 효율로 판단하며 직무 이름 개수나 확인하지 않은 종사자 통계로 결정하지 않는다. 소수 국소 직무에 종속된 전문 구현·특정 제품 명령·버전 철자·숫자의 단순 암기는 제외하거나 참고로 둔다. 필요한 수치·구문·관찰 자료는 문제의 보기로 제공한다. 수집 중에는 확정된 범위 적합성·출처·의미 중복·정답성을 확인하고 전체 수집 뒤 한 차례 일괄 필터링한다.

## 유한 검토와 품질 수용 기준

기존 프로젝트의 역할·독립성 원칙을 계승하고 별도 페르소나를 만들지 않는다. 원본 학습 목표와 기존 문항의 정답 근거를 대조하며 제목·키워드만으로 중복을 판정하지 않는다. 후보별 검토는 최초 1회와 수정 후 2회로 최대 3회다. 새로운 1차 근거가 기존 탈락 원인을 해결하는 경우에만 같은 목표의 재개방을 한 번 허용하며 계보 전체 최대 6회를 유지한다. ID·회차 변경으로 횟수를 초기화하지 않는다. 회차 시작 전 유한 판정 마감을 정하고 미완료 검사를 통과로 바꾸거나 무기한 보류를 반복하지 않는다.

정답·해설을 보지 않은 독립 풀이, 1차 출처·판본·권리와 범위 확인, 정답 유일성·동등 해석·반례 검토, 문안·접근성 검토, 자동 구조 검사를 동일 개정판에 적용한다. 해설은 실제 결과·관계·이유를 설명하고 묶음형은 구성 항목별 해설과 의도된 선택지 해설 공란 계약을 지킨다. 선택지 순서와 무관하게 의미가 유지돼야 한다. 실기 전체 모범 답안은 별도 화면으로 열고 닫으며 초점 복귀를 유지한다.

등록은 새 ID/개정판·은행 버전·manifest의 정합과 기존 문항·학습 기록 보존을 확인한다. 새 후보와 기준 은행의 실제 차이를 제한하고 필요 범위의 세션 생성·채점·해설 출력·저장·백업/복원·브라우저 회귀를 검증한다. 검사는 실행·재사용·실패·시간 초과·미실시를 구분한다. 완료된 장기 검사를 무조건 반복하지 않으며 실제 입력·의존성이 같은 증거만 재사용한다.

## 운영·백업·공개 기준

Asia/Seoul 기준 가장 빠른 권장 업데이트 간격은 4시간이다. 장애·승인 대기·근거 미확보·진행 중 작업이 있으면 슬롯을 이월하고 실제 상태를 기록한다. 진행 중인 회차를 중복 실행하지 않는다. 명시적인 즉시 진행 지시가 있으면 선행 회차와 필요한 선행 작업의 완료를 확인한 뒤 다음 회차를 권장 슬롯보다 일찍 시작할 수 있다. 조기 시작은 검증 생략이나 동시 실행을 허용하지 않으며 실제 시작 사유와 다음 회차 상태를 기록한다. 각 실제 세션은 검증된 변경의 누적 전체본·변경분 백업과 공개 배포 1회를 원칙으로 한다. 문제가 있으면 1회 스킵할 수 있으나 연속 2회는 다음 회차의 우선 해결·명시 보고 대상이다. 검증 실패·권한 거절을 무시한 배포나 빈 커밋으로 횟수를 채우지 않는다. 변경 없는 회차는 변경 없음으로 기록한다.

백업 완료에는 필요한 파일의 실제 Library 저장 확인이 필수다. 로컬 생성·복원 성공과 Library 저장을 별도로 기록한다. 채팅 첨부는 선택 사항이며 실패하면 생략할 수 있다. Library 저장 실패와 첨부 실패/미시도를 구분한다. 공개 계획서 사본은 전체 프로젝트·문제 은행·변경 이력의 복원 백업을 대신하지 않는다.

공개에는 검증된 서비스 파일과 별도 승인된 공개 문서만 포함한다. 내부 원장·원본 은행·구형 문제 내용·전체/변경 백업·개인자료·인증정보를 포함하지 않는다. 기존 서비스 파일과 제거된 경로의 경계를 보존하며 비강제 전송 후 정확한 커밋·배포 결과·공개 파일의 크기와 해시를 확인한다. 문서 사본은 별도의 공개 문서 백업으로 기록하며 세션의 서비스 배포 성공 횟수에 대신 넣지 않는다. 준비·전송·공개 확인의 실제 결과를 구분한다.

모바일 기준은 KS X3253:2025와2016판을 구분하고 KWCAG2.2/KS X OT0003:2022와 대조한다. [WAI 모바일 안내](https://www.w3.org/WAI/standards-guidelines/mobile/)와 플랫폼 평가 문서는 보조자료이며 국내 KS를 대체하지 않는다.

확보한 센스리더 제조사 도움말에는 일반 제품군v9.0·어센드v1.4까지 변경 이력이 있으나 자료 전체의 단일 발행판·날짜는 확인되지 않았다. 오래된 일반 절과 새 변경 이력이 혼재하므로 제품·에디션·버전·OS·브라우저·설정을 함께 확인한다. 해당 범위의 제조사 정정/변경 이력, 도움말 본문, 제조사 보충 안내 순으로 적용성을 판단하고 미해결 충돌을 현재 동작으로 단정하지 않는다. 도움말 원문·추출문·실행 파일은 공개하지 않는다.

추가 회차에도 문항 수 상한·최소량·목표별 할당량을 두지 않는다. 목표별 기존 충족·신규 필요·제외·남은 근거로 범위를 판단한다. 수집 중에는 확정 목표·출처·중복·정답성에 집중하며 직무 지역성 논쟁을 매 문항마다 반복하지 않는다. 후보3회·계보6회 제한은 유지하고 A04에서 초기화하지 않는다. 미확보 주장에는 원문 게이트를 적용하고 끝내 확인할 수 없는 주장은 제외하거나 검증 가능한 같은 목표로 좁힌다.

기존4시간 권장 간격과 잠금·단일 회차·검증/백업/공개 원칙은 유지하며 문서 갱신이 예약 변경이나 내용 회차 자동 시작을 뜻하지 않는다. 첫 추가 실행 전에 정상 운영 연결을 검증하고 과거 보호 규칙을 약화하지 않는다. 정제 PRD 공개는 서비스 배포 횟수나 Library 전체 백업 완료를 대신하지 않는다.
