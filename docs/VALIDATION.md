3. 오답은 최근 채점된 오답·부분점수만 포함한다. 미응답·미확정은 별도 기록에 보존하고 오답에 합치지 않는다
4. 이번 세트 오답은 다른 세트·다른 유형을 섞지 않는다. 현재 은행에서 불가능한 항목은 당시 해설 경로를 보존한다
5. 선택한 답을 제출하면 이미 채점된 답을 유지하면서 나머지 응답을 원자적으로 채점한다
6. 저장 후 나가기는 재개 가능하다. 시간제의 원래 마감은 유지된다. 종료는 재개 불가를 명시한다
7. 결과→해설→결과, 기록 필터와 돌아가기, 취소, 브라우저 뒤로·앞으로, 반복 클릭을 확인한다
8. 업데이트·파일 검사·답안 저장·해설 열기의 늦은 응답이 새로운 탐색을 덮어쓰지 않는다
9. 백업 파일 검사는 읽기 전용이고 적용은 별도 동작이다. 교체/삭제 취소는 기록을 보존한다
10. 실기 AI 자료는 미리보기·복사·다운로드만 제공한다. 서술형은 계속 미채점이다

## 통과: 실제 IndexedDB 격리 harness

2026-10-01 15:45:29 UTC,0.1.1에서 `qa/harness.html`의 9항목 모두 PASS. 일반 학습 기록과 별도인 QA 데이터베이스를 사용했습니다.

- 메인 파일 선택기에서 실제 다운로드 파일을 고른 UI 가져오기: 미실시. JSON 파서·실제 IndexedDB 가져오기/합치기/중복/rollback 검사는 별도로 통과
- 실제 저장 용량 소진·기기 절전·지원 대상 전체 브라우저 조합: 미실시. 제어된 실패/시계와 새로고침/만료 경계만 검증

## 발견한 문제와 수정

- 선택 해제한 줄 번호 textarea가 author display:block 때문에 노출됨: 전역 `[hidden]{display:none!important}`와 회귀 검사 추가, 실제 비표시 재확인
- 서술 루브릭과 고정답안 배점을 합산할 수 있는 프롬프트 모호함: 구역을 분리하고 비합산·서술 미작성 처리를 명시, 실기 서술 지시 포함
- 정상 새로고침 뒤 새 프롬프트 코드가 즉시 보이지 않음: 앱/모듈/CSS/QA 자원에 일관된 버전 URL을 도입하고 바닥글0.1.1 및 실제 새 프롬프트 출력을 확인. 캐시가 유일한 원인이라고 단정하지 않음
- 다운로드 URL을 고정1초 후 폐기하던 잠재적 경합:0.1.2에서 문서 수명 동안 유지하도록 보완. 브라우저가 문서 종료 시 정리하며 앱은 완료를 주장하지 않음. 이 변경만으로 실제 파일 수신을 검증했다고 보지 않음
