# PDF 목차 기반 공백 조사와 다음 회차 배분

## 분석 범위

2026-10-07의 regular.27(일반882개·시드14개), 선택지·전체 해설·이용 가능한 후보 이력과 두 PDF(72쪽·113쪽)를 목차별로 대조했다. [검토된 원본 분석·배분 JSON](2026-10-07-pdf-gap-allocation.json)에53개 목차 행, KWCAG33개 검사항목의 대표 연결,12개 연구 목표와 출처·조건을 보존한다. 전체 텍스트 추출과 일부 복잡한 페이지의 시각 점검을 구별하며, PDF 학습 본문은 공식 원발행기관의1차 근거와 나누어 사용한다.

이 문서는 연구·배분 계획이다. 후보 저작·검토 cycle은0회이고 기존 은행·원 대장을 수정하지 않았다. 목표당 후보·문항은 최대1개, 회차당 우선 조사 목표는 최대4개다. 이미 있는 정답·오답 해설의 해결 규칙을 이름·수치·속성만 바꿔 새 목표로 세지 않는다. 새 필수 지식과 타당한 선택지를 확보한 만큼만 후보를 시작한다.

## 유지해야 할 경계

- G03은 정의·분류 연구에 한정한다. 과거 round-002의 탈락 구현 목표를 다시 열거나 반복 영역 구현 전체를 포괄했다고 하지 않는다
- G09·G10은 PRD2.2·8.1·8.3의 문항별 적용판·실행환경 확인에 따라 ECMAScript2020으로 한정한다. 기존 ES2015 문항의 조건·키·해설은 보존하며 코드와 모든 대안은 후보 단계에서 독립 검증한다
- G07의 초점 가능성 조건과 MUST/SHOULD를 구별한다. G08의 규격상 읽기 관계를 모든 보조기술의 실제 지원으로 일반화하지 않는다
- G11의 새 지식과 타당한 오답을 확보하지 못하면 후보 등록 없이 조사 제외로 종결한다. 배정 수를 채우기 위한 후보를 만들지 않는다
- G12는 후보 시작 때 적용 법령판과 시행일을 다시 확인한다. 법정 명칭·시행 사실을 다루며 임상 수치·치료·개인의 등록 적격 판단을 하지 않는다
- 022의 격리19개,023의 후보19개·시작한20회 개정판 예약, 과거 탈락·검토 횟수와 재개방 제한을 모두 유지한다. 소실된 모든 원문을 회수했거나 현재896개 정답을 전부 새로 재인증한 분석으로 표현하지 않는다
