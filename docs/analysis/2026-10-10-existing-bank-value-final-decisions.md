- r017-policy-accessibility-s1-w02 — EAA 과도한 부담 평가 자료의 보관 기산점: 계속 제공되는 서비스와 평가서 작성일을 구별하는 논리는 있으나, 현재 지문에서 결정적인 근거는 EAA 평가기록 보관기간의 특수한 기산점이다. 정책 범위·적용 의무·예외 판단에 비해 이 정확한 행정기록 기산점 암기의 공통 훈련 효용이 낮다.
- r037-script-at-s5-w01 — NVDA 점자 뷰어의 주황색 대기 단계: 점자 셀 라우팅의 목적은 유용하지만 현재 답을 결정하는 단서는 특정 NVDA 뷰어의 주황·초록 표시와 대기 단계다. 이름·역할·상태나 초점 이동의 접근성 문제를 진단하는 훈련보다 제품 UI 색상 절차 기억에 치우친다.
- r027-policy-assistive-s5-w07 — NVDA 들여쓰기 톤의 탭 환산: 들여쓰기의 청각적 인지는 유용하지만 현재 문제의 정답은 탭 하나를 공백 네 칸 높이로 처리한다는 숨겨진 제품 상수를 알아야 정해진다. 6·6·8의 비교 자체는 단순하며 코드 구조를 진단하거나 설정을 선택하는 응용이 아니다.
- r014-dom-html-s3-w05 — ismap 클릭 좌표의 URL 직렬화: 좌표가 주어지고 ?x,y 직렬화 형식을 선택하는 것이 전부다. 서버 측 이미지 맵의 키보드 대안·목적 전달·대체 텍스트 문제를 다루지 않아 현재 형태의 전이 가치는 제한된다.
