# 웹접근성 2급 연습실

한국어·키보드 중심의 정적 학습 앱입니다. 필기 5과목과 실기 구현·점검을 연습하며, 서버 계정·AI API·외부 분석 도구 없이 동작합니다.

## 현재 상태: 개발자 점검용 미리보기

- 자체 제작 기능 검증용 필기 10문항(5과목 각 2개), 실기 4문항(구현 2개·점검 2개)
- 14개 모두 testOnly입니다. 개별 세션의 점수·해설은 보이지만 일반 학습 통계에서 제외합니다. 학습 기록에서 ‘테스트 시드 기록’을 선택하세요
- 공식 기출·공식 정답·전체 시험 범위·합격 예측을 제공하지 않습니다
- 검토 완료 일반 학습 문항이 과목마다 20개씩 확보되기 전에는 100문항 모의시험이 열리지 않습니다
- Windows/NVDA 수동 검증은 아직 미실시입니다. 자동 검사 통과만으로 NVDA 검증 완료를 주장하지 않습니다

## 실행

Node.js 22 이상(개발 검증: 24.19.0)과 Python 3만 있으면 됩니다. 런타임 및 개발 npm 의존성은 없습니다.

```sh
npm ci
npm run build
npm run check
npm test
npm run serve
```

브라우저에서 http://localhost:4173/ 를 엽니다. 이 안내는 개발자 본인 환경에서의 실행 방법입니다. 파일을 직접 여는 file:// 방식은 모듈·fetch 제한으로 지원하지 않습니다.

앱 코드 배포에는 버전이 붙은 모듈·CSS URL을 사용하며 바닥글에서 실제 로드된 런타임 버전을 확인합니다.

GitHub Pages 프로젝트 하위 경로에서도 작동하도록 모든 앱 자원은 상대 경로를 씁니다. 별도의 빌드 출력 디렉터리는 없으며, 저장소 루트 자체가 배포 가능한 정적 앱입니다. `npm run build`는 문제 은행을 검증하고 불변 릴리스 파일·SHA-256 manifest를 만듭니다.

## 기본 사용 (0.2.0)

1. 홈에서 **필기 5문항 바로 시작** 또는 **실기 2문항 바로 시작**을 누릅니다. 기본값은 시간 제한 없음이며 화면에 문항 수가 표시됩니다
2. 과목·시간을 바꾸려면 **과목·시간 직접 선택**을 엽니다. 시작 버튼은 처음부터 보이며 필수 안내 확인 단계가 없습니다. 기본 문항 수는 현재 은행에 맞지만 직접 입력한 수를 조용히 줄이지 않습니다
3. 답 선택·입력과 다음 문항 이동은 자동 저장입니다. **채점하고 해설 보기**를 누르면 그 답은 확정되어 바꿀 수 없습니다. 마지막의 **선택한 답 채점하고 종료**는 아직 채점하지 않은 선택·입력 답을 함께 채점합니다. 빈 답이나 자유 서술만 작성한 답은 고정 답안으로 채점하지 않습니다
4. **저장하고 나중에 이어 풀기**는 진행 상태를 유지합니다. 시간제는 나가도 원래 마감 시각까지 시간이 계속 흐르며 이를 나가기 전에 알립니다. 채점 없이 종료하는 별도 동작은 이어 풀 수 없음을 명시합니다
5. **오답 복습**은 학습 목표 개정판별 최근 채점 답이 오답 또는 부분점수인 문항만 보여 줍니다. 다시 맞히면 목록에서 빠집니다. 미응답·미확정은 오답에 섞지 않으며 원래 기록에 남습니다. 결과의 **이번 세트 오답·부분점수 복습**은 다른 세트와 섞이지 않습니다
6. 결과에서 **같은 범위 N문항 다시 시작**은 표시한 조건으로 새 연습을 바로 만듭니다. **연습 조건 바꾸기**는 준비 화면을 엽니다. 저장된 모든 연습은 학습 기록에서 찾고, 체험용 테스트 통계와 일반 학습 통계는 분리해 봅니다
7. 실기 코드는 읽기 전용입니다. 파일 선택·줄 이동·원문 복사·줄 번호 별도 보기를 사용할 수 있습니다. **외부 AI용 자료 미리보기**는 자료 확인·복사·다운로드만 제공하며 AI에 전송하거나 서술형 답안을 자동 채점하지 않습니다
8. 백업 JSON을 내려받아 보관합니다. 가져오기는 **파일 검사 → 내용/범위 확인 → 합치기 또는 교체 적용** 순서입니다. 교체·영구 삭제에는 별도 경고가 있습니다

앱 내부 뒤로 가기/취소와 주요 화면의 브라우저 뒤로·앞으로 이동을 지원합니다. 통계 필터는 앱을 사용하는 동안 보존합니다. 새로고침은 홈에서 이어 풀기를 제공합니다. 단, 공개 브라우저·키보드·보조기기 검증 상태는 아래 검증표를 먼저 확인하세요.

## 저장·시간·개인정보

- IndexedDB에 전체 문항 스냅샷, 선택지 순서, 기준 답안, 답과 확정 풀이를 저장합니다. 새 은행은 새 세션에만 적용합니다
- Web Locks로 한 세션의 동시 편집을 막고, 모든 쓰기는 IndexedDB 트랜잭션의 revision 비교로 충돌을 검출합니다. Web Locks 미지원 환경에서도 조용한 덮어쓰기를 허용하지 않습니다
- 시간제는 고정 만료 시각, 실행 중 단조 증가 시계, 재진입 시 벽시계를 함께 사용합니다. 탭·브라우저를 닫아도 시간이 연장되지 않습니다. 닫힌 동안 앱이 실행되지는 않으며 복귀 시 만료를 처리합니다
- 연장/무제한 전환은 설정 변경으로 기록합니다. 중단·전환한 시간제에는 최종 성적을 만들지 않습니다
- 저장 실패 시 입력을 막고 최신 화면 답안의 긴급 백업과 재시도를 제공합니다. 만료 후 재시도는 저장에 성공했던 답만으로 종료합니다
- JSON 가져오기는 최대 10MB·1000세션, 스키마·출처 URL·스냅샷·답·채점 일치 검사 후 원자 적용합니다. 여러 세션의 큰 백업은 한도 이하 파일로 나누고 개별 다운로드 버튼을 제공합니다. 한 세션 자체가 한도를 넘으면 원문 보존 전용·현재 앱으로 복원 불가임을 명확히 알립니다. 중복 ID 충돌은 합치기에서 기존 기록을 유지합니다
- 기록은 origin/브라우저/기기마다 다릅니다. 비공개 창 종료·사이트 데이터 삭제·배포 주소 변경으로 사라질 수 있습니다. 동기화나 영구 보관을 보장하지 않습니다
- 코드·답안은 텍스트로만 렌더링하고 eval/HTML 삽입을 사용하지 않습니다. 학습 코드의 취약한 예시는 실행하지 않습니다
- 답안과 정답은 정적 파일에서 확인할 수 있습니다. 시험 보안/감독 도구가 아닙니다. 호스팅 접속 로그는 별도로 존재할 수 있습니다

## 구조

- `src/domain.js`: 순수 출제·채점·시간·통계·정정·프롬프트·검증 함수
- `src/storage.js`: IndexedDB 트랜잭션, 편집 잠금, 은행 다운로드/해시 검증
- `src/backup.js`: 버전 포함 JSON 백업과 엄격한 복원 검사
- `src/app.js`: 네이티브 HTML 컨트롤과 한국어 화면
- `src/workflows.js`: 빠른 시작·오답 범위·답안 제출·기록 표시의 순수 작업 규칙
- `data/releases/<bankVersion>/bank.json`: 불변 콘텐츠
- `data/manifest.json`: 현재 적용할 완전한 릴리스 지시자
- `tests/`, `qa/`: 단위·독립 검증과 격리된 브라우저 저장소 테스트
- `docs/`: 데이터 계약, 운영, 출처 검토, 수용 기준, NVDA 수동 절차

PRD의 TypeScript 권장을 첫날의 무빌드 ES 모듈 JavaScript로 단순화했습니다. 대신 런타임 구조 검증, 순수 함수 분리, 고정 lockfile과 회귀 테스트를 사용합니다. 복잡한 에디터·프레임워크·서비스 워커는 도입하지 않았습니다.

## 검증과 제한

```sh
npm run verify
node scripts/validate-bank.mjs data/seed-bank.json
```

현재 Node 검증은 `docs/VALIDATION.md`를 참조하세요. `qa/harness.html`은 실제 브라우저에서 별도의 격리된 QA 데이터베이스로 트랜잭션·경합·가져오기·업데이트 실패를 검사합니다. 격리된 저장소 harness는 일반 학습 이력을 건드리지 않고 합성 문항을 공개 문제 은행에 넣지 않습니다. 별도의 `qa/viewport.html`은 버튼을 눌렀을 때 같은 앱을 320 CSS px 프레임에 여는 좁은 폭 검사입니다. 실제 모바일·브라우저 확대·NVDA 검사를 대신하지 않으며 일반 앱 저장소를 그대로 사용합니다.

제출된 무제한 답은 같은 세션에서 바꾸지 않습니다. 재시도는 새 세션으로 분리합니다. 실제 NVDA·확대·모바일·운영 배포 검증은 검증표에 수행 여부를 구분합니다. 대규모 보기에 대해 한 문항 연결 최대 1000개·정답 후보 최대 64개로 제한하며, 가능한 조합의 곱집합을 전개하지 않습니다.

## 콘텐츠 운영

`docs/OPERATIONS.md`와 `docs/DATA-CONTRACT.md`를 먼저 읽으세요. 원본 공식 첨부파일·유료 문제집·개인 학습 기록·인증정보를 이 저장소에 넣지 않습니다. 출처는 각 문항의 버전·절·확인일과 함께 링크합니다.

누적 새 문항 공개 마감은 **2026년 10월 17일 00:00 Asia/Seoul = 2026년 10월 16일 15:00 UTC**입니다. 공개 직전 `npm run release:check`를 실행합니다. `data/publication-state.json`의 최종 동결 상태도 검사합니다. 최종 공개 확인 후 동결하고 늦은 작업이 새 누적본을 배포하지 않게 합니다. 이미 공개된 최종 버전을 마감 뒤 읽고 학습하는 것은 계속 가능합니다.
